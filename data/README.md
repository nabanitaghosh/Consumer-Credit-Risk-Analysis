# Data

`Loan.csv` is the supplied Kaggle dataset used for this portfolio project.

Source:
https://www.kaggle.com/datasets/lorenzozoppelletto/financial-risk-for-loan-approval

The file contains 20,000 application records and 36 fields.

For SQL execution, import the CSV into SQLite as a table named `Loan`, preserving the original column names, then run `queries/00_setup.sql`.

Also, follow the other README file for more details
